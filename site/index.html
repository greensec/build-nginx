greensec build-nginx

nginx packages for Debian suites the official nginx.org repo dropped: stretch, buster, bullseye (amd64). Built with upstream pkg-oss packaging - drop-in replacements for the nginx.org nginx package.

Install

wget -qO- https://greensec.github.io/build-nginx/add-repository.sh | sh
apt-get install nginx

Freexian ELTS is required on these EOL dists - the script installs it automatically.
