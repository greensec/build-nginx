build-nginx

Debian packages of nginx for suites the official nginx.org repository dropped.

What is this?

nginx.org stopped publishing packages for end-of-life Debian releases - bullseye tops out at 1.30.5 while current stable is 1.30.x. This repository rebuilds the newest upstream stable release with nginx's own pkg-oss packaging inside clean containers of the target suite, and publishes the result as a signed APT repository on GitHub Pages.

The packages are drop-in replacements for the nginx.org build: same nginx package name, same version scheme (<ver>-<pkgrel>~<dist>), Conflicts:/Replaces: the Debian flavour packages. Where a host can use Debian's own nginx + Freexian Extended LTS instead, prefer that - ELTS backports the same fixes to the distro version.

Source and build pipeline: github.com/greensec/build-nginx.

Installation

Import the signing key and add the repository (replace <dist> with jessie, stretch, buster or bullseye):

curl -fsSL https://greensec.github.io/build-nginx/public.key \
  | gpg --dearmor -o /etc/apt/keyrings/build-nginx.gpg

echo "deb [signed-by=/etc/apt/keyrings/build-nginx.gpg] \
https://greensec.github.io/build-nginx/repo <dist> main" \
  > /etc/apt/sources.list.d/build-nginx.list

apt-get update
apt-get install nginx   # upgrades the nginx.org package in place

Equivalent helper: add-repository.sh (stretch, buster, bullseye - also sets up the Freexian ELTS repo below).

Freexian Extended LTS (required)

All supported suites are end-of-life - Debian ships no more security updates for them. Hosts need Freexian Extended LTS for the base-system libraries nginx links against (openssl, zlib, pcre): 

curl -fsSL https://deb.freexian.com/extended-lts/archive-key.gpg \
  -o /usr/share/keyrings/freexian-elts.gpg

echo "deb [signed-by=/usr/share/keyrings/freexian-elts.gpg] \
https://deb.freexian.com/extended-lts <dist>-lts main contrib non-free" \
  > /etc/apt/sources.list.d/freexian-elts.list

apt-get update

The <dist>-lts suites carry only Freexian's security updates - they supplement, not replace, the archive.debian.org sources.

Details

  • Architecture: amd64 only.
  • Suites: jessie, stretch, buster, bullseye; each needs archive.debian.org + Freexian ELTS + this repo to install.
  • Version scheme: <upstream>-<pkgrel>~<dist>, e.g. 1.30.8-1~bullseye - identical to the nginx.org scheme, so the packages upgrade cleanly over stale nginx.org installs.
  • Signing: dedicated GPG key, public.key; InRelease is signed.
  • Packaging source: unmodified upstream pkg-oss debian/ tree, minus what the EOL toolchains cannot do (debhelper compat is dropped to the distro level; jessie declares PCRE1).
  • Builds: GitHub Actions matrix builds, one per suite; a daily cron compares against nginx.org and dispatches a rebuild + publish automatically when upstream cuts a new release.
  • No HTTP/3 (QUIC): needs OpenSSL 3.x; these dists ship 1.0.x/1.1.x. nginx.org's own builds for these suites never had it either.
  • TLS 1.3: only on buster and bullseye (OpenSSL 1.1.1); stretch (1.1.0) and jessie (1.0.1) are limited to TLS 1.2.
  • Init: jessie ships the sysvinit script only (debhelper 9 predates dh_installsystemd); stretch and newer get a systemd unit.
Not affiliated. Unofficial rebuilds - not provided by NGINX/F5, the Debian maintainers, or Debian security. If a dist-upgrade path exists for your hosts, prefer it; this repo is a bridge for systems that must stay on an EOL suite.
Mixing with Debian nginx. These packages supersede both the stale nginx.org builds (higher version) and the distro nginx-* flavour packages (Conflicts:/Replaces:), so they replace either cleanly. The nginx.org list file can be removed or pinned away afterwards - it carries no newer builds for these suites anyway.
